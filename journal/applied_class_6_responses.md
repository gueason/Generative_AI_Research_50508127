## Activity 1

### 1. Storage and accessibility

Efficient file storage and organisation allow team members to locate the correct material quickly, reduce duplication, and avoid analysing an outdated version. A consistent structure also supports reliable backup, auditing, reproducibility, and collaboration throughout the research lifecycle.

### 2. File storage methods and access controls

Literature notes, scripts, de-identified datasets, and report drafts can be organised in a version-controlled folder structure, while large media can use managed cloud storage linked from the project documentation. Identifiable survey responses, interview recordings and transcripts, signed consent forms, and contact details require restricted access, encryption, and UQ-approved storage; only de-identified working copies should enter GitHub.

## Activity 2

### Why a good naming convention matters

A consistent naming convention makes a file's content, date, and version understandable without opening it, helping collaborators find and sort materials reliably. It also reduces ambiguous duplicates, prevents accidental use of outdated drafts, and makes automated processing and long-term data management easier.

### Unfamiliar point researched: metadata standards

Metadata provides structured information about a dataset's creator, purpose, collection method, variables, formats, dates, rights, and access conditions. Using an appropriate standard makes data easier to understand, discover, validate, and reuse, including after the original researchers leave the project. Effective implementation requires choosing a discipline-appropriate schema, defining required fields early, maintaining the metadata as the project changes, and storing it with the preserved dataset.

### How UQ Research Data Manager can make the checklist easier

An institutional research data-management system can centralise project storage, manage membership and access, support controlled sharing, and reduce reliance on personal devices. It can also make backup, continuity, ownership, retention planning, and documentation easier by keeping research records in a managed project space. Researchers must still classify sensitive data correctly, configure access appropriately, maintain useful metadata, and follow ethics, consent, legal, and disciplinary requirements.
