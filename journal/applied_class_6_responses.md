## Activity 1

### Storage and accessibility

Organising files makes them easier to find and helps the group avoid using the wrong version. It also makes backup and collaboration easier.

### File storage methods

Articles, scripts, de-identified data and reports can be stored in organised project folders. Interview recordings, consent forms and identifiable survey data need restricted access and should not be uploaded to GitHub.

## Activity 2

### Why is a good naming convention important?

Clear file names help people understand and sort files without opening them. Dates and version numbers also reduce confusion between older and newer copies.
