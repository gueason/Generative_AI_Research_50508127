# Data management summary

- Store working files in clearly named, numbered folders.
- Keep at least one managed backup and verify that it can be restored.
- Use Git for scripts, documentation, and de-identified small datasets.
- Keep consent forms and identifiable participant data in restricted UQ-approved storage.
- Give collaborators only the minimum access needed for their role.
- Document file formats, variable definitions, processing steps, and versions.
- Review retention, disposal, sharing, and embargo requirements before data collection.
